Logboek Norwin - Het web is voor iedereen - Blok 2

Ik weet nog niet wat ik wil doen, maar ik wil sowieso de mogelijkheden van css ontdekken en toepassen.

Voor mij is een website webby als het de informatie op een toegankelijke maar toch creatieve manier levert. Het moet zo vormgegeven zijn dat de gebruiker zonder al teveel zoeken de hele website kan navigeren. Het inspireert me als een website uniek is voor die persoon, maar toch duidelijk genoeg is om de gebruiker optimaal alles te laten zien wat de website te bieden heeft.

Een digital garden is een eigen omgeving die helemaal vrij is voor eigen creativiteit en stijl. Het hoeft niet perse te voldoen aan de standaard conventies van een website van bijvoorbeeld een bedrijf met winstdoelen. Het mag in je eigen unieke stijl worden gemaakt. 
We hebben in de klas in groepen allemaal een artikel gelezen over digital gardens en meningen erover. De visie in veel van de teksten kwam neer op een vrije omgeving die losstaat van grote techplatformen als Instagram en X. Het moet openstaan voor toevoegingen, feedback en moet net als een tuin steeds door kunnen groeien. Zo kan het internet een plek worden waar mensen ook hun eigen dingen creeeren om zichzelf uit te drukken en niet allemaal meegaan in de huidige staat van het internet, die ze als minder creatief en persoonlijk zien.

Ik heb geleerd hoe je in css door fonts allerlei creatieve dingen kan maken, zoals de letters een shadow geven voor meer diepte of een gloeiend effect.
Ik heb geleerd hoe fonts werken en wat regular, bold, italic en bold italic zijn. Ik heb geleerd hoe @font-face werkt, dat je via font-family de font via de naam kan koppelen aan bepaalde eigenschappen als bijvoorbeeld de font size, weight en kleur. Ook is de font style belangrijk: dit kan bepalen of de tekst als regular wordt weergegeven of als italic (schuin). Daarnaast heb ik geleerd dat Google Fonts in een website gebruiken een absolute no-go is, tenzij het font wordt gedownload.


Ik heb geleerd om aanpassingen aan de website te maken door in de index.html bepaalde dingen als de naam aan te passen en deze via source control een passende naam te geven voor overzicht. Zo is het duidelijker welke aanpassingen ik heb gemaakt. Ik heb in dit geval de naamaanpassing uitgelegd door "Naam Aangepast" erbij te zetten.

Ik heb geleerd om een domeinnaam voor mijn website te reserveren via TransIP en te koppelen via GitHub. Ik heb een project geopend in VScodium door het bestand met de MacOS arm structuur te downloaden en deze te openen in VScodium.

Ik heb een zelftest gedaan om te testen wat ik uit voorgaande blokken heb onthouden.
